# Reference Resources

This document lists the publicly available resources used as references for the GeoJSON datasets for **Munster Technological University (MTU)** campuses.

The resources include campus maps, building floor plans, location information, accessibility resources, and directions published by MTU and its affiliated services.

They are provided for reference and attribution purposes and may be useful when verifying campus locations, building layouts, and other geographical information.
