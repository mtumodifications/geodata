# Geodata

An open collection of GeoJSON datasets mapping all campuses of **Munster Technological University (MTU)**.

## Documentation

- **GeoJSON datasets:** See the [GeoJSON documentation](docs/README.md) for details about the available datasets, their structure, and usage.
- **Geocore package:** See the [Geocore documentation](package/geocore/README.md) for information about the `geocore` package.

## Data Sources

This project uses publicly available information and resources published on the internet, including campus maps, building floor plans, addresses, and other geographical references.

These resources are used to compile, organise, and produce the GeoJSON datasets. Sources are documented in the [reference resources](docs/README.md#reference-resources).

The project is an independent collection of geographical data and is not an official MTU publication.
